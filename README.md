# Sales Forecasting M5 - Student Project Submission

## Project Overview
This repository contains a **Sales Forecasting Project** developed as part of a student assignment for company review. The goal is to predict future retail sales using advanced time-series forecasting methods on the M5 dataset.

## Dataset
The dataset used for this project is the **M5 Forecasting - Accuracy** dataset. 
You can access and download the dataset from the following link:
- **Dataset Link**: [https://huggingface.co/datasets/kashif/M5/tree/main](https://huggingface.co/datasets/kashif/M5/tree/main)

## Methodology
The project explores and compares several forecasting models:
- **SARIMA**: Seasonal Autoregressive Integrated Moving Average for capturing seasonality.
- **Prophet**: Facebook's procedure for forecasting time series data based on an additive model.
- **LSTM**: Long Short-Term Memory neural networks for deep learning-based sequence prediction.

## Repository Structure
- `notebooks/`: Jupyter notebooks containing the exploratory data analysis (EDA) and model implementation.
- `Source Code/`: Python scripts for data processing and model training.
- `Output/`: Generated forecasts and model evaluation metrics.
- `requirements.txt`: List of Python dependencies required to run the project.

## Instructions for Reviewers
To review and run this project:

1.  **Clone the Repository**:
    ```bash
    git clone <repository-url>
    cd Sales_forecasting_m5
    ```

2.  **Install Dependencies**:
    Ensure you have Python 3.8+ installed.
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Analysis**:
    Open the notebooks in the `notebooks/` directory to see the step-by-step analysis and model training process.
    ```bash
    jupyter notebook
    ```

## Results
The project demonstrates the effectiveness of different models on the M5 dataset. Detailed performance metrics and visualizations can be found in the notebooks.
